@AGENTS.md

When working in a folder, also read its `AGENTS.md` (`src/core/`, `src/cli/`, `viewer/`,
`examples/`, `docs/`). The documentation rule in `AGENTS.md` is mandatory: update the
documentation site (`docs/`), `README.md` and the relevant `AGENTS.md` in the same change as any
user-visible behaviour.

The writing rule in `AGENTS.md` is mandatory too: never write the em dash character (U+2014) in
anything you generate or modify (code, comments, messages, documentation, Markdown, commits);
always use the ASCII hyphen `-` (U+002D) instead.
